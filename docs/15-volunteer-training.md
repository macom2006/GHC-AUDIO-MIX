# 15 — Volunteer Training

A three-tier path. Nobody skips a tier. Nobody runs a service alone until they have
completed Tier 2 and been signed off.

---

## Tier 1 — Assistant (2–4 weeks)

**Can do:** set up the stage, patch cables, change batteries, run the pre-service
checklist alongside a mentor.
**Cannot do:** touch the console during a service.

### Must know
- [ ] The power-up and power-down order, and **why** it matters
- [ ] How to read the patch sheet (`patch/input-patch.csv`)
- [ ] How to coil and store a cable properly (over-under)
- [ ] Battery policy: fresh in every pack, every service, no exceptions
- [ ] How to place a vocal mic, a drum mic, and a DI
- [ ] Never to hot-patch a live microphone
- [ ] Where the spare cables, mics and DIs live

### Sign-off
Can complete the T−90 and T−75 sections of the checklist unsupervised, and has done
so correctly three weeks running. **Signed:** ____________ **Date:** ________

---

## Tier 2 — Operator (2–3 months)

**Can do:** run a full service under the supervision of a Tier 3 engineer, then
independently once signed off.

### Must know
- [ ] Gain structure — what −18 dBFS means and why we use it
- [ ] The full channel strip: HPF, gate, EQ, compressor, and what each one does
- [ ] The DCA layout, by heart
- [ ] Every scene and when to recall it
- [ ] The SPL targets, and how to use the meter
- [ ] **That the house mix and the broadcast mix are different mixes**
- [ ] How to identify and notch a feedback frequency
- [ ] The ambience mute rule for prayer and altar calls
- [ ] How to start and verify the recording

### Practical assessments
- [ ] Build a full mix from Scene 1 in under 20 minutes using virtual soundcheck
- [ ] Identify three feedback frequencies by ear and notch them
- [ ] Run a complete service with a mentor sitting beside them, no interventions
      required
- [ ] Recover from three simulated failures: a dead wireless mic, a muted main, a
      lost AES50 link
- [ ] Explain the broadcast mix offsets and why each one exists

### Sign-off
Three consecutive services run with no significant issues.
**Signed:** ____________ **Date:** ________

---

## Tier 3 — Engineer (6+ months)

**Can do:** everything, including modifying the system configuration — and is
responsible for updating this repository when they do.

### Must know
- [ ] How to program the console from a blank state using these documents
- [ ] How to ring out the PA and set room EQ with measurement tools
- [ ] Sub/main alignment and delay-ring calculation
- [ ] Full broadcast chain: loudness metering, the mastering chain, lip-sync
- [ ] Logic Pro multitrack and virtual soundcheck setup from scratch
- [ ] Scene scope, safes, and show file backup
- [ ] How to train a Tier 1 and Tier 2 volunteer
- [ ] How to update this repository — and the discipline to actually do it

### Responsibilities
- Owns the show file and its backups
- Runs mid-week virtual soundcheck training
- Reviews the service log monthly and acts on patterns
- Maintains this documentation

---

## The five rules every volunteer learns first

1. **The message is the point.** Production serves the gathering. If the sermon is
   inaudible, nothing else you did that morning mattered.
2. **When in doubt, mute.** Especially during prayer, ministry and pastoral moments.
   Privacy is a stewardship issue, not a technical preference.
3. **Louder is not better.** Watch the meter, not your instinct.
4. **The musicians' monitors belong to the musicians.** Never change an in-ear mix
   without being asked.
5. **Write it down.** Every problem, every change, every fix. The log is how the
   team gets better instead of relearning the same lessons.

## Suggested training schedule

| Week | Activity |
|---|---|
| 1 | Shadow a Tier 3 through a full Sunday. Observe only. |
| 2 | Tier 1 duties: setup, patching, batteries |
| 3–4 | Tier 1 duties unsupervised; begin reading docs 01–06 |
| 5–8 | **Mid-week virtual soundcheck sessions** — build mixes with no congregation |
| 9–12 | Run worship-set portions live with a mentor at the desk |
| 13+ | Run full services with the mentor observing |
| Sign-off | Three clean services → Tier 2 |

**Virtual soundcheck is the training tool.** A volunteer who has mixed twenty
sessions from recordings arrives at their first live service already competent. A
volunteer who has only ever learned live has made every mistake in front of the
congregation. Use the recordings.
